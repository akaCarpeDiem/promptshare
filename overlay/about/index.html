About PromptShare

Last updated: October 1, 2026 · Applies to https://promptshare.fun/

What this site is

PromptShare is an educational gallery of AI-generated images, video, animation, audio, and small games. Each plate shows the output together with the prompt that created it, so you can study which words did the work.

The purpose is study and learning. PromptShare is not a model vendor, not a prompt marketplace, and not a place to generate a new image or video. It is an educational curated gallery of operator-published plates. You do not need an account to browse. Public visitor uploads and community publishing are not offered. Studio names such as Mira, Jonah, and Noor are curated attribution for study plates, not an open creator network.

AI-generated media

The media on this site is AI-generated. A still, clip, track, or game can be fictional, stylized, or unlike a record of a real event. A plate is a study pair — this file, this prompt — not a news report and not professional advice.

  • Publisher plates credit the maker and link to the page that released the prompt and the file together.
  • Studio plates are labeled PromptShare studio. PromptShare wrote that prompt and generated that file. The date on those plates is the day the pair was made.
  • A pair is left out when the prompt and the file cannot be checked against each other.
  • Notes under a prompt are PromptShare’s reading of that sentence. They are not the creator’s commentary.

How plates and categories work

The home screen shows one plate at a time: the output first, then the prompt. Underlined words open a short study note. Prompt breakdown opens the same notes in order against the full sentence.

Image categories include Landscapes, Cities, Street, People, Portraits, Cyberpunk, Futuristic, Animals, Fictional Animals, Myths, Comic book art, Anime, Food, Architecture, Space, Fantasy, Vehicles, and Nature. A Videos section uses the same category list; clips are filled in later by the operator, one category and one prompt at a time.

  • Animation is cartoon, stop-motion, clay, paper, and other drawn or puppet craft.
  • Ads are video commercials for a product or company.
  • Gaming plates are small playable games. The prompt is the spec the game was built from.
  • Other chips are subject rooms: landscape, street, architecture, food, nature, animals, cyberpunk, educational, and music.

Advertising

PromptShare loads the Google AdSense script for site review. When ads are approved, they may appear on the site; they are not placed above a plate image. The Privacy Policy and Cookies page describe what that means.

Plate JSON for apps

Curated plates are available as JSON from the existing API. A future native app can reuse the same payload; there is no separate app product on this site.

Canonical app fields (also returned on creation objects):

  • id — plate id
  • imageURL — media URL (alias of API mediaUrl)
  • prompt — final prompt text
  • model — model name
  • notes — array of step/note objects (id, position, prompt, model, text / note)
  • creatorHandle — author handle (from author.handle)
  • visibility — public or unlisted
  • createdAt — ISO-8601 publish time

Endpoints: GET /api/creations/{id}, GET /api/feed. Each creation also includes a nested plate object with the same canonical fields. Current API names (mediaUrl, steps, author, userId, title, tags, mediaKind) remain for existing clients.

Permalink HTML for crawlers stays at /p/{id}.
