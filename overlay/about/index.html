About PromptShare

Last updated: October 11, 2026 · Applies to https://promptshare.co/

What this site is

PromptShare is an educational gallery of AI-generated images, videos, and small browser games. Each plate shows the output together with the prompt that created it, so you can study which words did the work.

The purpose is study and learning. PromptShare is not a model vendor, not a prompt marketplace, and not a place to generate a new image or video. It is an educational curated gallery of operator-published plates. There are no accounts and no sign-in: everything on the site can be browsed as it is. Public visitor uploads and community publishing are not offered.

AI-generated media

The media on this site is AI-generated. A still, clip, or game can be fictional, stylized, or unlike a record of a real event. A plate is a study pair — this file, this prompt — not a news report and not professional advice.

  • Every plate in the gallery is a PromptShare studio plate: PromptShare wrote the prompt and generated the file with the model named on the plate.
  • The prompt shown is the text that was sent. A pair is left out when the prompt and the file cannot be checked against each other.
  • Notes beside a prompt are PromptShare’s reading of that wording. They are interpretations, not a statement from the model’s maker, and the same phrase can land differently in another prompt or another model.

How plates and categories work

A plate page shows the output first, then the prompt. The phrases that did the work are marked in the colour of the job they do: subject, place, style, light and weather, camera and framing, motion and time, detail, or guardrail (what to leave out). Each mark has a short note, listed in order beside the prompt.

The Words page collects phrases that recur across the gallery. Pick one to read what it usually changes and to compare every image and video whose prompt uses it.

Images and Videos share one category list: Landscapes, International Cities, US Cities, Street, People, Portraits, Cyberpunk, Futuristic, Animals, Fictional Animals, Myths, Comic book art, Anime, Food, Architecture, Space, Fantasy, Vehicles, and Nature. New plates are added by the operator, one prompt at a time.

Games are small playable browser games, each written by an AI model from a single prompt. The prompt is the spec the game was built from. A game keeps a Top 10; scores are saved under a display name you choose, and no account is needed.

Advertising

PromptShare loads the Google AdSense script for site review. When ads are approved, they may appear on the site; they are not placed above a plate image. The Privacy Policy and Cookies page describe what that means.

Plate JSON for apps

Curated plates are available as JSON from the existing API. A future native app can reuse the same payload; there is no separate app product on this site.

Canonical app fields (also returned on creation objects):

  • id — plate id
  • imageURL — media URL (alias of API mediaUrl)
  • prompt — final prompt text
  • model — model name
  • notes — array of step/note objects (id, position, prompt, model, text / note)
  • creatorHandle — author handle (from author.handle)
  • visibility — public or unlisted
  • createdAt — ISO-8601 publish time

Endpoints: GET /api/creations/{id}, GET /api/feed. Each creation also includes a nested plate object with the same canonical fields. Current API names (mediaUrl, steps, author, userId, title, tags, mediaKind) remain for existing clients.

Permalink HTML for crawlers stays at /p/{id}.
